# MOMART VIP

Aplicación web móvil para que los clientes de los reservados VIP de Momart (Cádiz) pidan bebidas y extras desde el QR de su mesa. El MVP contempla carta digital, configuración de acompañamientos, carrito, pago, seguimiento del pedido y un panel de comandas para el personal de barra.
